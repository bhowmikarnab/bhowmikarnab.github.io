# bhowmikarnab.github.io

Personal academic website of **Arnab Bhowmik**, Research Scholar (PhD, Physics) at IIEST Shibpur —
<https://bhowmikarnab.github.io>

**To update the site (papers, blog posts, notes, CV), read [HOW-TO-UPDATE.md](HOW-TO-UPDATE.md).**

Built with plain HTML, CSS and JavaScript; GitHub Pages turns the Markdown posts and notes into pages (Jekyll).

| Folder / file              | What it holds                                              |
|----------------------------|------------------------------------------------------------|
| `_data/publications.yml`   | the papers (Publications page + "Recent works" on Home)    |
| `_posts/`, `_notes/`       | blog posts and notes, one Markdown file each               |
| `_templates/`              | starter files to copy for a new post or note               |
| `_data/code.yml`           | code projects shown on the Code page                       |
| `index.html`, `publications.html`, `code.html`, `notes.html`, `blog.html`, `404.html` | the pages |
| `_layouts/`, `_includes/`  | shared page frame: head, header, footer, article layout    |
| `assets/`                  | CSS, JavaScript, pictures, the CV PDF and the background music |
